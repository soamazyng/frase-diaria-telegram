# Compartilhar com quem você ama

O bot nasceu para uma única pessoa. Depois de um tempo em funcionamento, o
irmão dela gostou da ideia — e queria receber a mesma frase, todo dia,
também.

## A mesma frase, para todo mundo

Não são duas frases sorteadas separadamente: é **uma única escolha**,
entregue a todos os destinatários autorizados ao mesmo tempo. As duas pessoas
recebem exatamente o mesmo texto, no mesmo instante — como se estivessem
lendo a mesma página, ainda que em conversas separadas.

## Um problema com um não afeta o outro

Se por algum motivo a entrega falhar para uma pessoa — um bloqueio, uma
instabilidade pontual — isso nunca atrasa nem cancela a entrega para as
demais. Cada destinatário tem sua própria confirmação; um problema é só dele,
até ser resolvido.

## Ainda é pessoal

Pedir uma frase extra (`/frase`) continua sendo individual: só quem pediu
recebe a resposta. Compartilhar a diária não significa que tudo vira coletivo
— cada pessoa ainda tem sua própria relação com o bot.

## Um conjunto pequeno, escolhido a dedo

Não existe cadastro aberto nem convite automático. Quem recebe a diária é
decidido manualmente, por quem mantém o bot — pensado para uma família ou um
grupo pequeno de pessoas próximas, não para uma audiência.
